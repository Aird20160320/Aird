# 扇贝单词

一个在浏览器里运行的单词记忆练习，流程参考扇贝英语：选一本词书，按每天的新词数量学习，到期的词进入复习，完成当天计划后打卡。

进度保存在这台浏览器的本地存储里，不需要账号。词义、例句和助记是为这个练习原创编写的，和扇贝官方的词库、账号、商标无关。

## 学习怎么走

- 首页看今日新学和复习，点「开始学习」。
- 先看单词，回忆释义，再揭开意思。
- 不认识、模糊、认识、太简单会排进不同的复习间隔。不认识的词会在这一组里再出现。
- 学满当天目标就打卡。还可以再学 5 个。
- 词书、生词本、拼写自测和近 7 天的统计都在底部导航里。

桌面学习时可以用空格显示释义，用 1 到 4 选择熟悉程度。
