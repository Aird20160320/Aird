# 扇贝日语

一个在浏览器里运行的日语单词练习。学习法参考扇贝：选一本词书，按每天的新词数量学习，到期的词进入复习，完成当天计划后打卡。

词书有 N5、N4、N3 和日常会话。翻开卡片先回忆读音和意思，再用「不认识 / 模糊 / 认识 / 太简单」决定下次什么时候见。也可以把词放进生词本，或看着中文写出平假名。

进度保存在这台浏览器里，不需要账号。读音、释义和例句是为这个练习写的，和扇贝官方的词库、账号无关。

## 学习怎么走

- 首页看今日新学和复习，点「开始学习」。
- 先看日语，回忆读音和意思，再揭开。
- 不认识的词会在这一组里再出现。
- 学满当天目标就打卡。还可以再学 5 个。

桌面学习时可以用空格显示释义，用 1 到 4 选择熟悉程度。
