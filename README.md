# 扇贝日语

一个在浏览器里运行的日语单词练习。学习法参考扇贝：选一本词书，按每天的新词数量学习，到期的词进入复习，完成当天计划后打卡。

词书有 N5、N4、N3 和日常会话。也可以自己新建词书，写上日语、读音和中文。翻开卡片先回忆读音和意思，再用「不认识 / 模糊 / 认识 / 太简单」决定下次什么时候见。统计页的记忆曲线会把正在记的词标在遗忘曲线上：刚记住接近 100%，降到 80% 左右再次复习。每个词的详情里也能看到它自己的曲线。也可以把词放进生词本，或看着中文写出平假名。

进度和自建的词保存在这台浏览器里，不需要账号。读音、释义和例句是为这个练习写的，和扇贝官方的词库、账号无关。

## 学习怎么走

- 首页看今日新学和复习，点「开始学习」。每天新学几个可以在今日计划里改，常用 5、10、15、20、30，也可以自己填 1 到 50。
- 先看日语，回忆读音和意思，再揭开。
- 不认识的词会在这一组里再出现。
- 学满当天目标就打卡。还可以再学 5 个。

## 自己的词书

在「词书」里点「新建词书」，写上名称，再添加日语、读音和中文释义。读音可以用平假名或片假名。建好之后，新学、复习和打卡和内置词书一样。清空学习记录时，自建的词书会留下来，打卡和熟悉程度会消失。删除某一本自建词书时，里面的单词会一起去掉。

桌面学习时可以用空格显示释义，用 1 到 4 选择熟悉程度。

## 打开桌面版

需要先装好 Node.js。在项目目录里执行：

```bash
npm install
npm run desktop
```

会弹出一个「扇贝日语」窗口。关掉窗口，应用就退出。进度留在这台电脑的这个应用里。

只在浏览器里看的话，用 `npm run dev`，然后打开 http://localhost:5173 。

```bash
npm test
```

构建：

```bash
npm run build
npm run preview
```
